# 护眼提醒

面向 Windows 10/11 64 位的后台护眼提醒程序。它遵循 20-20-20 原则：每 20 分钟提醒用户眺望约 6 米（20 英尺）外至少 20 秒。

程序只在本地运行，不需要账号或网络连接，也不播放声音、不记录使用历史。

## 用户安装

1. 获取 `EyeRelax-<版本号>-win-x64.exe` 安装包。
2. 双击安装包并按提示完成安装。安装仅作用于当前 Windows 用户，不需要 Node.js 或管理员权限。
3. 安装完成后程序自动启动；可从开始菜单的“护眼提醒”再次启动。安装器不创建桌面快捷方式。

如出现 Windows 安全提示，请先确认安装包来源可信。升级时直接运行新版本安装包；若要清除全部设置，请先卸载旧版本。

## 用户使用

程序启动后常驻任务栏通知区域，不显示主窗口。若图标被折叠，请点击“显示隐藏的图标”查找“护眼提醒”。

右键托盘图标可执行：

- **立即提醒**：立刻显示提醒窗口，即使当前已暂停也可使用。
- **暂停提醒 / 恢复提醒**：暂停会隐藏窗口并取消当前计时；恢复后重新开始 20 分钟计时。
- **设置**：设置推迟时长和开机自启。
- **退出**：完全关闭程序。

提醒窗口显示在鼠标所在屏幕的右下角：

- 点击“已休息”后，开始下一轮 20 分钟计时。
- 点击“推迟 X 分钟”后，X 分钟后再次提醒；推迟可重复执行，不等同于完成休息。
- 按钮支持鼠标操作；页面不再提供全局 `Enter`/`Esc` 快捷键，避免提醒出现时抢占输入。

锁屏或睡眠期间计时暂停，解锁或唤醒后继续剩余时间。程序重启后会重新开始 20 分钟计时。

设置仅保存推迟时长（1～10 分钟，默认 3 分钟）和开机自启状态（默认开启）。卸载程序会清理这两项本地数据和开机自启项。

## 构建与发布

维护环境需要 Node.js 22+ 与 npm。Windows 实机用于生成正式安装包和最终验证；Linux/WSL2 可用于编译与自动化测试。

```sh
npm ci
npm test
npm run package:win
```

安装包生成在 `release/` 目录，文件名为 `EyeRelax-<版本号>-win-x64.exe`。该文件是唯一需要分发给终端用户的交付物；不要分发源代码、`node_modules/` 或 `dist/`。

常用命令：

| 命令 | 用途 |
| --- | --- |
| `npm run typecheck` | 仅执行 TypeScript 类型检查。 |
| `npm test` | 构建并运行自动化测试。 |
| `npm run dev` | 以后台托盘模式启动。 |
| `npm run dev:smoke` | 打开最小验证窗口，检查 Electron 图形链路。 |
| `npm run package:win:dir` | 生成仅供检查的 Windows 目录包。 |
| `npm run package:win` | 生成正式 Windows x64 NSIS 安装包。 |

发布前应在 Windows 10 或 Windows 11 64 位机器上确认：安装后自动进入托盘、设置持久化、立即提醒/暂停/恢复可用、重复启动不会生成第二个实例，以及卸载会清理本地数据。

## 项目结构与约束

```text
src/core/       计时、状态机和设置等平台无关逻辑
src/main/       Electron 主进程、窗口、托盘与 IPC
src/platform/   系统事件、计时器、设置和开机自启适配
src/preload/    受限 IPC 桥接
src/renderer/   提醒和设置页面
tests/          Node.js 内置测试
build/          NSIS 安装器配置
```

核心逻辑通过一次性计时器和单调时钟驱动，避免高频轮询。渲染进程启用 `contextIsolation`、关闭 `nodeIntegration`，仅能经由预加载脚本公开的 IPC 调用主进程。
